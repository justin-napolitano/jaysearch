# Standards Bibliography

This directory collects standards and primary references for execution, messaging, telemetry, and error contracts used by the platform research package.

These files are meant to be cited from future markdown documents so the repo can reuse one local bibliography surface instead of scattering raw external links across many notes.

Current contents:

- `execution-and-observability-standards.md`
- `agent-error-contract-standards.md`
- `token-economy-and-api-first-execution.md`

Use these bibliography notes as the local citation anchor when drafting new design documents.
