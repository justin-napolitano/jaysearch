How To Read This

Counts are generated from manifests

Bronze table count is the number of generated upload/landing table artifacts. Silver and Gold are currently shown as one canonical contract each per registry where bronze exists; detailed silver/gold table expansion is a review decision. Cardinality range is the min-to-max row count across generated bronze targets. UDFs/procedures are not emitted in the current slice; validation is generated as SQL tables and row-count statements.
