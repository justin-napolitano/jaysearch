# Planning Merge-Readiness Game

## Objective

The planning merge-readiness game proves that planning artifacts are ready to advance into governed contract state or implementation-facing work.

## Inherited Concepts

This game inherits:

- shared board identity
- evidence rules
- authority rules
- common referees

It narrows:

- legal moves
- win conditions
- acceptable blockers

## Proof Criteria

Typical proof criteria include:

- planning artifacts validate
- blockers are visible
- key decisions and constraints are explicit
- contract projection readiness is justified

## Failure Condition

If planning outputs still require hidden assumptions, the proof game fails even if the planning conversation felt productive.
