# ExecPlan Game

## Objective

The ExecPlan game converts intent into governed contract state. It is the commitment layer between exploration and execution.

## Inputs

- planning outputs
- implementation scope
- validation requirements
- review obligations

## Outputs

- governed ExecPlan artifacts
- validation contract
- approved scope boundaries

## Win Condition

The ExecPlan game succeeds when a plan is specific enough to govern work without requiring hidden assumptions.

## Relationship to Child Games

The ExecPlan game governs both planning and implementation games. It does not replace them; it constrains them.
